# PyMORGAN & PyMORGAN Suite v1.261122.1 Release Notes

**Release Date:** November 22, 2026  
**Tag:** `v1.261122.1`  
**Previous Release:** `v1.261103.2`

---

## Highlights

**PyMORGAN v1.261122.1** is a major feature, interoperability, and analysis release spanning everything added since `v1.261103.2`: full **reproducible workflows** (copy-on-write Undo/Redo, runnable Python script export, `.pmrecipe.toml` recipes, CLI/GUI batch execution, and `.pmproj` project sessions), **real multi-detector 2D-IR loaders & community interoperability** (`UoS_2DIR`, `RAL_RAW`, `RAL_Proc`, `Helios_UFS`, Glotaran `.ascii`/`.nc`, FAIR 1D & 2D HDF5, and universal `load_auto`), **advanced 1D scatter removal**, **golub-pereyra VARPRO multi-order spectrograph calibration**, **electronic 2D-ES & QuickControl enhancements**, **unit-aware interactive kinetics/spectra cutting**, and **GUI browser/info upgrades**.

---

## Reproducible Workflows, Undo/Redo, Recipes, Batch Processing & `.pmproj` Sessions

- **Processing Provenance, Undo/Redo & Python Script Export (`pymorgan.provenance`):**
  - Copy-on-write `HistoryManager` & `ProcessingStep` tracking across mutating `Dataset1D` and `Dataset2D` operations (including `background_correct`, `shift_t0`, `crop`, `mask_probe_regions`, `remove_scatter`, `apply_chirp_correction`, `subtract_solvent`, `subtract_shockwave`, `process`, `subtract_spectrum`, `set_active_state`, and `set_active_detector`).
  - Full GUI integration under the new **Edit** menu: **Undo** (`Ctrl+Z`), **Redo** (`Ctrl+Shift+Z` / `Ctrl+Y`), **Reset Dataset to Raw**, interactive **Processing History...** inspector (`ProcessingHistoryDialog` with step parameters, selective state revert, and recipe export), and **Copy/Export Python Script** (`ds.to_python_script()`).
- **Declarative Processing Recipes (`.pmrecipe.toml`, `pymorgan.recipe`):**
  - Human-readable TOML recipe format storing ordered step parameters and relative-first portable paths for auxiliary inputs (solvent references, chirp fits, calibration files, 2D reference maps).
- **Headless CLI & GUI Batch Execution (`pymorgan.batch`):**
  - Added `BatchProcessDialog` (*File → Batch Process Folder...*) and CLI entrypoints (`pymorgan batch` / `pymorgan-batch`) supporting auto-detected inputs, multi-process `--workers`, `--dry-run` preview, `--on-error skip|stop`, per-dataset format overrides (`pdat`, `p2dat`, `hdf5`, `glotaran_ascii`, `glotaran_nc`, `png`), and structured `batch_report.csv` / `batch_report.json` outputs.
- **Portable Workspace Sessions (`.pmproj`, `pymorgan.project`):**
  - Save and restore complete GUI sessions (*File → Open / Save Project*, `Ctrl+S` / `Ctrl+Shift+S`), including portable relative paths for root folder, 1D/2D datasets, slow-modulation state, active 2D detector channel, full processing history, steady-state/FTIR overlays, axis limits, and per-project settings overrides, with interactive missing-file relocation.
- **Recent Folders & Zero-I/O Dataset Filtering:**
  - Persistent MRU history (`settings.recent_dirs`, `settings.max_recent_dirs`) wired to *File → Recent Folders* and `RootDir` path autocompletion, plus instant substring filtering (`Ctrl+F` / `Esc`) in both 1D and 2D browsers without re-scanning the filesystem.

## New 1D/2D Loaders, Community Interoperability & Universal Auto-Detection

- **UoS & RAL 2D-IR Loaders + Multi-Detector Switching (`pymorgan.twoD`):**
  - Implemented full readers for `UoS_2DIR` (`.2D` + `.DT`/`.LG`/`CalibratedProbe.csv`/`w0.csv`), `RAL_RAW` (LIFEtime interferograms), and `RAL_Proc` (LIFEtime processed delay slices).
  - Added first-class multi-detector channel management (`Dataset2D.set_active_detector`, supporting `DET1`, `DET2`, and `Combined (DET1+DET2)` with per-detector probe vectors, single-scan tensors, history recording, and a GUI *Detector* selector).
- **Surface Xplorer Binary Reader (`Helios_UFS`):**
  - Direct binary reader for Ultrafast Systems `.ufs` (IEEE-754 big-endian v1/v2 streams) preserving experimental metadata blocks, unit scaling, and `_scan*.ufs` single-scan discovery.
- **Glotaran / pyglotaran & FAIR 1D/2D HDF5 Interoperability (`pymorgan.oneD.interop`, `pymorgan.hdf5_meta`):**
  - Added `Glotaran_ASCII` (`.ascii`) and CF-1.8 NetCDF4 (`Glotaran_NC`, `.nc`) readers and writers (`to_glotaran_ascii()`, `to_glotaran_nc()`) built directly on `h5py` dimension scales with zero extra heavy dependencies (`xarray`/`netCDF4` not required).
  - Upgraded 1D `HDF5` export/load (`save_1D_hdf5` / `load_1D_hdf5`) and added 2D `HDF5_2D` (`Dataset2D.to_hdf5()` / `load_2D_hdf5`) with gzip+shuffle compression, CF attributes, SHA-256 source hashes, detector/state cubes, and round-tripped JSON processing provenance (`history_json`).
- **Universal Format Auto-Detection (`pymorgan.detect`):**
  - Added `detect_format`, `load_auto`, and `FormatMatch` to identify 1D, 2D, steady-state, `.pmproj`, and `.pmrecipe.toml` inputs by magic headers and file/directory signatures, wired to GUI *Open* (`Ctrl+O`), OS file associations / CLI launch arguments, `QFileOpenEvent`, drag-and-drop, and batch discovery (with confidence-tie disambiguation dialog).
- **PyMESS `CalibratedProbe.csv` Precedence & Embedding + QuickControl / 2D-ES Upgrades:**
  - Prefer local `CalibratedProbe.csv` (across data, `calib/`, `Cal+Chirp/`, and root folders) when loading PyMESS 1D and 2D datasets, and added `embed_calibrated_probe_h5` / *Pre-Processing → Include CalibratedProbe.csv in .h5 Dataset…* (`actionEmbedProbeCalH5`) with `/calibration/original_probe_axis` backup.
  - Added QuickControl trailing-footer & partial-scan handling, undersampled pulse-shaper frequency unfolding, electronic 2D-ES dual-axis/unit support, and live 2D shot-rotation with in-memory reprocessing.

## 1D Processing, Scatter Removal, Chirp & Unit-Aware Interactive Plotting

- **Multi-Band Scatter & Dynamic Background Removal (`pymorgan.oneD.scatter`, `ScatterRemovalDialog`):**
  - Two-tier automatic detection of primary and coupled 2nd-order grating harmonic scatter bands, joint scatter-basis + local TA polynomial separation (`local_svd`, `taylor`, `warped`), broadband envelope scaling, per-scan cleaning with recomputed `Zstdv` error bars, and transmittance-space correction.
- **Interactive 1D Plot Enhancements:**
  - Added `Shift+Click` on the 1D contour plot to overlay/inspect the averaged 1D noise trace (`Zstdv`) and modifier-scroll contour zoom.
- **Unit-Aware Kinetics Cuts, Slices & Transient Spectra Dialogs:**
  - Separated native unscaled contour coordinates (`probe_axis_to_native`) from scaled UI axes across `10^3 cm-1`, `eV`, `THz`, and `nm`, fixing double-scaling in kinetics cuts, `_compute_zref`, non-interactive 2D slices, and small-span ROI `RectangleSelector` boxes.
  - Made 1D and 2D transient-spectra prompts delay-unit-aware (displaying dataset units/ranges, accepting `fs`/`ps`/`ns`/`us`/`µs`/`ms`/`s` suffixes, and computing in-range defaults).
- **Chirp & Pixel-Axis Fixes:**
  - Refined 1D Cauchy chirp dispersion bounds, Morlet wavelet edge-onset fitting, time-unit dialog labels, and uncalibrated pixel-axis handling.

## Calibration Engine & Updater Reliability

- **Baseline & Global Multi-Order Dispersion Calibration (`pymorgan.cal`):**
  - Added `pymorgan.cal.baseline` estimators (`arPLS`, `AsLS`, `SNIP`, `IModPoly`, `legacy_poly`) selectable independently for Sample, Standard, Both, or None.
  - Added Golub-Pereyra VARPRO global multi-order (0th + 1st + 2nd derivative) dispersion solver with PCHIP resampling, padded pre-cut reference baselines, blank SNR weights, joint PSF convolution, and exact quadratic/cubic IR dispersion inversion.
  - Improved high-contrast overlay visibility and updated UniGE TRUVIS-II defaults (`540.0 nm` CWL, peak cross-correlation pre-alignment, rejecting uncalibrated pixel indices in metadata).
- **Updater Rate-Limit Resilience:**
  - Added zero-quota GitHub Atom/web release fallbacks, ETag/cooldown caching, and headless test guards to `pymorgan.gui.updater`.
